# Sources

Status: living; checked against the code on 2026-10-02.

A source is the material a content owner brings, kept as the text Braivo teaches from, with the link and the file it came from ([product.md](../product.md), core job 1). Source content is authoritative ("Content first"), so derived content cites it by quoting it, and Braivo refuses a quote it cannot find ("Grounded AI"). Whoever extracts the text, a content owner's own tools or Braivo's AI, adds it the same way. Owners add material in the console, from the CLI, or over the HTTP API (`apps/server/api/index.ts`).

## Rules

- **sources-1:** Only an `owner` or `admin` of an organization adds, lists, or reads its sources, uploads or downloads its files, and cites from or reads its citations; anyone else gets 403. Another organization's source reads as one that does not exist, and citing it is refused as citing a missing one is. `apps/server/application/sources.test.ts`, `apps/server/application/citations.test.ts`, `apps/server/api/app.test.ts`
- **sources-2:** A source has a title and exactly one of `text`, `cues`, or `pages`. The title is trimmed and 1 to 500 characters; the text is stored in Unicode NFC with `\n` line endings and otherwise as sent. Blank text, a NUL, or an unpaired surrogate is refused rather than repaired, and a request over 10 MB answers 413. `apps/server/content/source.test.ts`, `apps/server/application/sources.test.ts`, `apps/server/api/app.test.ts`
- **sources-3:** A source may name a link and a language. The link must be `http` or `https`, without a user name or password, at most 2048 characters, and is stored canonical. The language is a BCP 47 tag stored canonical (`es-mx` as `es-MX`) whose primary subtag has two or three letters, so `Spanish` is refused; whether the language is registered is not checked. `apps/server/content/source.test.ts`, `apps/server/application/sources.test.ts`, `apps/server/api/app.test.ts`
- **sources-4:** A source Braivo cannot store answers 400 with an `error` naming the field, or the cue or page by index, and what would fix it, never repeating what was sent. A body not in the documented shape answers a bare 400. Nothing is stored either way. `apps/server/application/sources.test.ts`, `apps/server/api/app.test.ts`, `apps/server/content/transcript.test.ts`, `apps/server/content/pages.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-5:** A source never changes, and nothing removes it. A revision is another source, and the first keeps its text, so a citation keeps meaning the passage it was checked against. `apps/server/application/sources.test.ts`
- **sources-6:** A source is its content: adding one the organization already has, with the same title, text, link, language, timing or pagination, and original, answers 201 with the existing ID and stores nothing, even when writers race. A difference in any of those makes another source; another organization's identical source is its own. `apps/server/persistence/source.test.ts`, `apps/server/content/source.test.ts`
- **sources-7:** A recording may be sent as cues, `{ at, text }`: each cue's words go on a line of their own as the source's text, and the source keeps its timing, where each line starts and its second. 1 to 100,000 cues, at seconds from 0 to 86,400, in order, each with words. `apps/server/content/transcript.test.ts`, `apps/server/api/app.test.ts`
- **sources-8:** A document may be sent as pages, `{ page, text }`: the pages are joined a blank line apart in the order sent, and the source keeps its pagination, where each page starts and its label. A label is as printed (`12`, `iv`), at most 16 characters without control characters, and need not be ordered or unique. 1 to 10,000 pages, each with words. `apps/server/content/pages.test.ts`, `apps/server/api/app.test.ts`
- **sources-9:** The library lists an organization's sources by title, without text; reading one adds its text, and its timing or pagination when it has one. Positions are in code points. A field a source lacks is absent, not null, and every read answers `Cache-Control: private, no-store`. `apps/server/application/sources.test.ts`, `apps/server/api/app.test.ts`
- **sources-10:** A file is uploaded as the request's raw body, up to 50 MB, typed by its `Content-Type` (the media type alone, lowercased); an empty file or a type that is not a media type answers 400, explained. Its ID is its SHA-256. The same bytes again answer the same and keep one record, which takes the content type last sent, so a wrong type is fixed by uploading again. The bytes are written on every upload, so uploading again also restores bytes a store lost; until then, downloading the file answers 500. `apps/server/api/app.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-11:** An upload without a `Content-Type`, with a form's type or `text/plain`, or from another origin answers 403, so a page on another site cannot upload through a signed-in browser. `apps/server/api/app.test.ts`
- **sources-12:** A file is downloaded as its type with `Content-Disposition: attachment`, `Content-Security-Policy: sandbox`, `X-Content-Type-Options: nosniff`, and `Cache-Control: private, no-store`, never rendered. An ID the organization has no file for, or one that is not a SHA-256, answers 404. `apps/server/api/app.test.ts`
- **sources-13:** An installation keeps files in a directory or an S3-compatible bucket, as `BRAIVO_FILES` names; a key can never name anything outside the directory. With none set, the file routes answer 501 explaining why, and everything else works on text alone. `apps/server/api/app.test.ts`, `apps/server/storage/storage.test.ts`
- **sources-14:** A source may name its original, by the `fileId` its upload answered, which must be one of the organization's files; otherwise 400 says to upload it first. `apps/server/api/client.contract.test.ts`, `apps/server/content/source.test.ts`
- **sources-15:** A citation links an objective, or a task, to a passage of a source, many to many. Braivo locates the quote: any run of whitespace matches any run, and everything else matches exactly after NFC. A quote must occur exactly once, overlapping occurrences counted, and be 1 to 2000 characters. It is stored as a range in code points, `start` at its first character and `end` just past its last. `apps/server/content/citation.test.ts`, `apps/server/application/citations.test.ts`, `apps/server/api/app.test.ts`
- **sources-16:** A batch of citations is stored whole or not at all, and a citation already stored is stored once. A refused quote answers 400 naming it and why: `"Citation 1: the quote occurs more than once in the source; quote more of it."`, or for a task `"Task 0, citation 0: …"`. One request locates at most 200 quotes, and a task cites at most 10; beyond either it answers a bare 400. An objective or source that is not the organization's answers 403. `apps/server/application/citations.test.ts`, `apps/server/application/tasks.test.ts`, `apps/server/api/app.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-17:** An objective's citations read back with their ranges and quotes, by source and position. A task's cited passage carries its quote and its source's title and link. From a timed transcript it also carries `at`, the second at which the cue holding its first character starts; from a paged document it carries `page`, the label of the page it starts on. It never carries the source's text or positions. `apps/server/application/citations.test.ts`, `apps/server/api/app.test.ts`, `apps/server/content/transcript.test.ts`, `apps/server/content/pages.test.ts`
- **sources-18:** `braivo sources add <file | -> --organization <slug>` adds a file's text, titled by the file's name without its extension; standard input needs `--title`. The slug is the one in the console's address, of an organization the signed-in person manages; another is refused, listing theirs. A `.vtt` or `.srt` file is sent as cues: markup dropped, the rolling repeats of auto-generated captions skipped by position, and a line really said twice kept; a caption whose timing it cannot read, or captions run together without a blank line between them, are refused, naming the line, rather than words lost. Text with form feeds, as `pdftotext` writes, is sent as pages labelled by position from 1, or from `--first-page`, the book's number of the first, 1 to 999999, leaving out pages without words; with none left, it says the PDF needs OCR first. `--first-page` on text without form feeds, or on captions, is refused before anything uploads. Text with a NUL or an unpaired surrogate is refused before it is split at form feeds, which keeps a PDF's bytes with a NUL, given in place of its text, from being taken for pages. `apps/server/cli/captions.test.ts`, `apps/server/cli/remote.test.ts`
- **sources-19:** `--original <file>` uploads, as its extension's type, only a document (PDF, Office, OpenDocument, EPUB), an image other than SVG, audio, or video, judged on the file a link resolves to and refused before it is read. Before uploading, it refuses what it can tell Braivo would — blank text, text with a NUL or an unpaired surrogate, malformed captions, pages none of which has text, a slug naming no organization the person manages — so those upload nothing; a refusal only Braivo makes, such as a bad title, link, or language, comes after the upload. Then it adds the source naming the file. `apps/server/cli/originals.test.ts`, `apps/server/cli/remote.test.ts`
- **sources-20:** The console lists an organization's sources by title, marking each one's language and whether its original is kept, and links each to its page, which shows its text and offers its link and its original as a download. Its add form takes a title, text, link, language, and original file, leaves out what is blank, and refuses before sending a file over 50 MB or of a type the upload refuses. It uploads the original first, adds the source naming it, then opens it. It shows Braivo's explanation of a refusal, and holds the form still while sending. `apps/console/routes.test.tsx` (the 50 MB check untested)

## Boundaries

- Braivo's own AI reading a file into pages (`POST …/files/:fileId/text`, which the console's form calls when a file comes without text) and drafting from a source: [generation](generation.md).
- Objectives, courses, tasks, keys, task twins (cited passages are part of what makes a task the same), retirement, and the MCP tools that add sources: [authoring](authoring.md).
- When a learner sees a task's passages, only after grading, and how the learn app shows a moment or page: [learner loop](learner-loop.md).
- Sign-in, bearer tokens, roles, which hosts accept a write, and refusing to delete an organization that still has sources or files: [access](access.md).
- Not here yet: deleting anything, Braivo fetching a link, and uploads over 50 MB (see Gaps).

## Decisions

- [ADR 0020](../adr/0020-source-content.md): a source is an immutable, normalized text snapshot, extracted by whoever holds the file.
- [ADR 0021](../adr/0021-citations.md): citations are quotes Braivo locates once, stored as code-point ranges, refused with an explanation.
- [ADR 0024](../adr/0024-idempotent-authoring.md): a source's identity is its content, so adding it again returns it.
- [ADR 0025](../adr/0025-timed-transcripts.md): a recording enters as cues, and a passage names its moment.
- [ADR 0026](../adr/0026-paged-documents.md): a document enters as pages, and a passage names its printed page.
- [ADR 0028](../adr/0028-original-files.md): originals are content-addressed files in a store the installation chooses.

## Gaps

| Gap                                                                                                 | Impact                                                                                                       | Next step                                                                       |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| Nothing deletes a source, a file, or a citation                                                     | Mistakes and test material stay in the library; an organization with any of them cannot be deleted           | Decide what removing a source does to derived content and learning history      |
| A source cannot be edited, title included                                                           | A typo in a title means adding the source again, and what cites the first keeps showing the typo to learners | Decide whether a title can be renamed without making another source             |
| Files over 50 MB have no upload path                                                                | A video cannot be kept as an original                                                                        | A presigned upload straight to the store, recorded afterwards (ADR 0028)        |
| Unreferenced files stay stored: after the server refuses a source, or when the owner leaves mid-add | Storage grows with files nobody sees; no listing shows them                                                  | List an organization's files, or collect those no source names                  |
| Learners cannot open an original                                                                    | A learner told "p. 12" needs their own copy of the book                                                      | Product decision: whether an organization may share originals with its learners |
| Braivo never fetches a link: a YouTube video's or an article's text must be extracted by the sender | A teacher with only a link needs `yt-dlp` or an agent before adding it                                       | Fetch captions or an article's text server-side, kept as the source's link      |
| A source's text is at most 10 MB per request                                                        | A long book must be split into several sources by hand                                                       | Split by chapter in the CLI, or raise the limit once locating quotes is indexed |
