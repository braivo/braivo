# Sources

Status: living; checked against the code on 2026-11-03.

A source is the citable text Braivo teaches from, of material a content owner brings, kept with the link and the file it came from ([product.md](../product.md), core job 1). Source content is authoritative ("Content first"), so derived content cites it by quoting it, and Braivo refuses a quote it cannot find ("Grounded AI"). Whoever extracts the text, a content owner's own tools, the console reading a PDF's text layer, or Braivo's AI, adds it the same way. Owners add material in the console, from the CLI, or over the HTTP API (`apps/server/api/index.ts`); a learner practising on their own does so as the owner of an organization of their own (access-31).

Three things are kept apart. A _file_ is an original's bytes, kept as provenance (sources-10 to sources-14). A _source_ is a citable text representation of a file, of part of one, or of material with no file at all; one file may back several sources. _Learning content_, objectives, tasks, and courses, is prepared from sources for a purpose ([authoring](authoring.md)): one source may serve several, such as a question bank's text serving both an exam course and a vocabulary course. A source's `text`, `pages`, or `cues` say how its text is located, not what kind of file it came from, and its `language` is the material's, not the learner's.

## Rules

- **sources-1:** Only an `owner`, `admin`, or `author` of an organization ([ADR 0048](../adr/0048-author-role.md)) adds, lists, or reads its sources, uploads or downloads its files, and cites from or reads its citations; anyone else gets 403. Another organization's source reads as one that does not exist, and citing it is refused as citing a missing one is. `apps/server/application/sources.test.ts`, `apps/server/application/citations.test.ts`, `apps/server/api/authoring.test.ts`, `apps/server/api/materials.test.ts`, `apps/server/api/roles.test.ts`
- **sources-2:** A source has a title and exactly one of `text`, `cues`, or `pages`. The title is trimmed and 1 to 500 characters; the text is stored in Unicode NFC with `\n` line endings and otherwise as sent. Blank text, a NUL, or an unpaired surrogate is refused rather than repaired, and a request over 10 MB answers 413. `apps/server/content/source.test.ts`, `apps/server/application/sources.test.ts`, `apps/server/api/materials.test.ts`
- **sources-3:** A source may name a link and a language. The link must be `http` or `https`, without a user name or password, at most 2048 characters, and is stored canonical. The language is a BCP 47 tag stored canonical (`es-mx` as `es-MX`) whose primary subtag has two or three letters, so `Spanish` is refused; whether the language is registered is not checked. `apps/server/content/source.test.ts`, `apps/server/application/sources.test.ts`, `apps/server/api/materials.test.ts`
- **sources-4:** A source Braivo cannot store answers 400 with an `error` naming the field, or the cue or page by index, and what would fix it, never repeating what was sent. A body not in the documented shape answers a bare 400. Nothing is stored either way. `apps/server/application/sources.test.ts`, `apps/server/api/materials.test.ts`, `apps/server/content/transcript.test.ts`, `apps/server/content/pages.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-5:** A source never changes, and nothing removes it. A revision is another source, and the first keeps its text, so a citation keeps meaning the passage it was checked against. `apps/server/application/sources.test.ts`
- **sources-6:** A source is its content: adding one the organization already has, with the same title, text, link, language, timing or pagination, and original, answers 201 with the existing ID and stores nothing, even when writers race. A difference in any of those makes another source; another organization's identical source is its own. `apps/server/persistence/source.test.ts`, `apps/server/content/source.test.ts`
- **sources-7:** A recording may be sent as cues, `{ at, text }`: each cue's words go on a line of their own as the source's text, and the source keeps its timing, where each line starts and its second. 1 to 100,000 cues, at seconds from 0 to 86,400, in order, each with words. `apps/server/content/transcript.test.ts`, `apps/server/api/materials.test.ts`
- **sources-8:** A document may be sent as pages, `{ page, text }`: the pages are joined a blank line apart in the order sent, and the source keeps its pagination, where each page starts and its label. A label is as printed (`12`, `iv`), at most 16 characters counted in NFC, the form it is kept in, without control characters, and need not be ordered or unique. 1 to 10,000 pages, each with words. `apps/server/content/pages.test.ts`, `apps/server/api/materials.test.ts`
- **sources-9:** The library lists an organization's sources by title, without text; reading one adds its text, and its timing or pagination when it has one. Positions are in code points. A field a source lacks is absent, not null, and every read answers `Cache-Control: private, no-store`. `apps/server/application/sources.test.ts`, `apps/server/api/materials.test.ts`
- **sources-10:** A file is uploaded as the request's raw body, up to 50 MB, typed by its `Content-Type` (the media type alone, lowercased); an empty file or a type that is not a media type answers 400, explained. Its ID is its SHA-256. The same bytes again answer the same and keep one record, which takes the content type last sent, so a wrong type is fixed by uploading again. The bytes are written on every upload, so uploading again also restores bytes a store lost; until then, downloading the file answers 500. `apps/server/api/materials.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-11:** An upload without a `Content-Type`, with a form's type or `text/plain`, or from another origin answers 403, so a page on another site cannot upload through a signed-in browser. `apps/server/api/materials.test.ts`
- **sources-12:** A file is downloaded as its type with `Content-Disposition: attachment`, `Content-Security-Policy: sandbox`, `X-Content-Type-Options: nosniff`, and `Cache-Control: private, no-store`, never rendered. An ID the organization has no file for, or one that is not a SHA-256, answers 404. `apps/server/api/materials.test.ts`
- **sources-13:** An installation keeps files in a directory or an S3-compatible bucket, as `BRAIVO_FILES` names; a key can never name anything outside the directory. With none set, the file routes answer 501 explaining why, and everything else works on text alone. `apps/server/api/materials.test.ts`, `apps/server/storage/storage.test.ts`
- **sources-14:** A source may name its original, by the `fileId` its upload answered, which must be one of the organization's files; otherwise 400 says to upload it first. `apps/server/api/client.contract.test.ts`, `apps/server/content/source.test.ts`
- **sources-15:** A citation links an objective, or a task, to a passage of a source, many to many. Braivo locates the quote: any run of whitespace matches any run, and everything else matches exactly after NFC. A quote must occur exactly once, overlapping occurrences counted, and its words, joined by single spaces, be 1 to 2000 characters, so a source's layout padding does not count against a passage read back. It is stored as a range in code points, `start` at its first character and `end` just past its last. `apps/server/content/citation.test.ts`, `apps/server/application/citations.test.ts`, `apps/server/api/authoring.test.ts`
- **sources-16:** A batch of citations is stored whole or not at all, and a citation already stored is stored once; two batches sharing citations, sent at once in any order, both succeed. A refused quote answers 400 naming it and why: `"Citation 1: the quote occurs more than once in the source; quote more of it."`, or for a task `"Task 0, citation 0: …"`. One request locates at most 200 quotes, and a task cites at most 10; beyond either it answers a bare 400. An objective or source that is not the organization's answers 403. `apps/server/application/citations.test.ts`, `apps/server/application/tasks.test.ts`, `apps/server/api/authoring.test.ts`, `apps/server/api/client.contract.test.ts`
- **sources-17:** An objective's citations read back with their ranges and quotes, by source and position. A task's cited passage carries its quote and its source's title and link. From a timed transcript it also carries `at`, the second at which the cue holding its first character starts; from a paged document it carries `page`, the label of the page it starts on. It never carries the source's text or positions. `apps/server/application/citations.test.ts`, `apps/server/api/authoring.test.ts`, `apps/server/api/materials.test.ts`, `apps/server/content/transcript.test.ts`, `apps/server/content/pages.test.ts`
- **sources-18:** `braivo sources add <file | -> --organization <slug>` adds a file's text, titled by the file's name without its extension; standard input needs `--title`. The slug is the one in the console's address, of an organization the signed-in person manages; another is refused, listing theirs. A `.vtt` or `.srt` file is sent as cues: markup dropped but a WebVTT speaker's name, kept as `Anna: ` before the line, the rolling repeats of auto-generated captions skipped by position, and a line really said twice kept; a caption whose timing it cannot read (minutes or seconds past 59 included) or that ends before it starts, or captions run together without a blank line between them (told by a line that looks like a timing, mistyped or not), are refused, naming the line, rather than words lost. Text with form feeds, as `pdftotext` writes, is sent as pages labelled by position from 1, or from `--first-page`, the book's number of the first, 1 to 999999, leaving out pages without words and naming them (ten at most, then how many more), since a scanned page needs OCR first; with none left, it refuses the text, saying so. `--first-page` on text without form feeds, or on captions, is refused before anything uploads. Text with a NUL or an unpaired surrogate is refused before it is split at form feeds, which keeps a PDF's bytes with a NUL, given in place of its text, from being taken for pages. `packages/cli/captions.test.ts`, `packages/cli/remote.test.ts`
- **sources-19:** `--original <file>` uploads, as its extension's type, only a document (PDF, Office, OpenDocument, EPUB), an image other than SVG, audio, or video, judged on the file a link resolves to and refused before it is read. Before uploading, it refuses what it can tell Braivo would — blank text, text with a NUL or an unpaired surrogate, malformed captions, pages none of which has text, a slug naming no organization the person manages — so those upload nothing; a refusal only Braivo makes, such as a bad title, link, or language, comes after the upload. Then it adds the source naming the file. `packages/cli/originals.test.ts`, `packages/cli/remote.test.ts`
- **sources-20:** The console lists an organization's sources by title, marking each one's language and whether its original is kept, and links each to its page, which shows the first 20,000 characters of its text in a box Tab reaches, named "Source text", saying its full length when it is longer and showing all of it on request, the focus moving to the text, and offers its link and its original as a download. Its add form takes a title, text, link, language, and original file, its hint saying the link is kept for reference and what it links to not imported, titles it from the file's name while the title is blank or still a file's (never one typed), leaves out what is blank, suggests common languages by name and sends a language's English name typed in full, as the browser names it, as its two-letter tag, the rest as typed, and refuses before sending a title Braivo would refuse (blank, over 500 characters, or not text), or a file of a type the upload refuses, or over 50 MB, which it then clears so that adding again keeps the text without it. Text pasted over 10 MB is refused before the original uploads (sources-2). It uploads the original first, adds the source naming it, then opens it if the owner stayed on the page. It shows Braivo's explanation of a refusal, and holds the form still while sending, naming the step under way. Leaving for another page, by Back too, with anything entered but not added asks first, and so does reloading or closing the tab where the browser allows; staying keeps it all, and no draft of it is kept. Leaving while it is sent asks nothing. `apps/console/test/sources.test.tsx`
- **sources-21:** Reading a source may ask for part of it, by one of `pages` (positions from 1, not labels, both ends included), `seconds` (from the cue being said at the first), or `characters` (code points), each as `A-B` or `A-` to read on. It answers the source as listed, at most 20,000 characters of its text with their `start` and `end` in the whole text's positions, its `length`, and the timing or pagination entries those characters overlap, at most 500; one asking too much is cut at the last page or cue starting within those limits, else the last line break, else at 20,000, and carries `next`, the `characters` range of the rest asked for. A range the source cannot answer, such as page 40 of 30, pages of a source without them, or a start at or past its end, answers 400 saying what it can answer. Asking for no part reads it whole, as sources-9 says. `read_source` always reads a part, from the start unless asked otherwise, and the citation check still reads the whole source. `apps/server/content/slice.test.ts`, `apps/server/api/materials.test.ts`, `apps/server/api/client.contract.test.ts`, `apps/server/mcp/server.test.ts`
- **sources-22:** In the console, a PDF attached with no text pasted is read from its own text layer, in the browser and without AI, unless the owner chooses Braivo's AI where it is on (generation-14); nothing is uploaded while it is read. Every physical page is listed in order with its outcome: read; to check, text that may not be what the page shows (a scan with a few typed lines, or mostly a font's codes); no text; or could not be read (a page pdf.js cannot open, or whose contents name what the file lacks, such as an image or a font program). Its label is the PDF's own (`/PageLabels`), else its place from 1. The text is as the PDF draws it: lines joined by a space within a paragraph, paragraphs a blank line apart, a printed hyphen at a line's end kept, ligature characters spelled out (`ﬁ` as `fi`), in NFC; columns drawn line by line across the page interleave, and a word split by a soft hyphen reads with a space. Reading stops past 1,000 pages, 10 MB of text, 5 seconds without a page finishing, or 60 seconds in all, saying which and what to do, as it does for a PDF locked with a password or damaged; one only forbidding copying is read. It says how far it has come, and Cancel or leaving the page stops it. `apps/console/test/pdf-reader.browser.test.tsx`, `apps/console/lib/pdf/text.test.ts`, `apps/console/test/sources-pdf.test.tsx`
- **sources-23:** The pages read are reviewed in the add form before anything is stored, one page at a time: a list of the pages, each with its position, printed label, outcome, and decision, narrowed on request to those the reader flagged, and the page shown, with Previous and Next through the pages listed; edits stay with their page when moving. Each page's printed label and text can be corrected; "The first page is printed page" numbers them all from it, and cleared, returns them to the PDF's own labels or places; each page is kept or left out. A page read cleanly starts kept; a flagged one waits for the owner's decision and links to that page of the file in the browser's own viewer. Save source refuses, before uploading anything, a page undecided, a kept page without a letter or digit or with what Braivo cannot store, a label sources-8 refuses, nothing kept, or pages over 10 MB (sources-2), showing the page the refusal is about with the focus at its control; it says how many pages it saves and leaves out, uploads the PDF, and adds the kept pages in order as a paged source naming it (sources-8, sources-14). Where Braivo's AI is on, "Read the whole file with AI instead" has it read the file (generation-14), once, and its pages replace the review only once that succeeds, so a failure keeps the owner's edits; leaving meanwhile asks first. While the review is open, the Text field and the file stay as they were; discarding it keeps the rest of the form, and leaving asks first, as sources-20 says. `apps/console/test/sources-pdf.test.tsx`

## Boundaries

- Braivo's own AI reading a file into pages (`POST …/files/:fileId/text`, which the console's form calls when a photo, or a PDF the owner has the AI read, comes without text) and drafting from a source: [generation](generation.md).
- Objectives, courses, tasks, keys, task twins (cited passages are part of what makes a task the same), retirement, and the MCP tools that add sources: [authoring](authoring.md).
- When a learner sees a task's passages, only after grading, and how the learn app shows a moment or page: [learner loop](learner-loop.md).
- Sign-in, bearer tokens, roles, which hosts accept a write, and refusing to delete an organization that still has sources or files: [access](access.md).
- A source is text: what a file shows only in pictures, such as a road sign a statement is about, is not in its source, and no task shows a picture yet. Citing a passage proves it occurs in the source, not that the source is complete or that a task follows from it.
- Not here yet: deleting anything, listing files, uploading several at once, Braivo fetching a link, and uploads over 50 MB (see Gaps).

## Decisions

- [ADR 0020](../adr/0020-source-content.md): a source is an immutable, normalized text snapshot, added the same way whoever extracts it.
- [ADR 0021](../adr/0021-citations.md): citations are quotes Braivo locates once, stored as code-point ranges, refused with an explanation.
- [ADR 0024](../adr/0024-idempotent-authoring.md): a source's identity is its content, so adding it again returns it.
- [ADR 0025](../adr/0025-timed-transcripts.md): a recording enters as cues, and a passage names its moment.
- [ADR 0026](../adr/0026-paged-documents.md): a document enters as pages, and a passage names its printed page.
- [ADR 0028](../adr/0028-original-files.md): originals are content-addressed files in a store the installation chooses.
- [ADR 0048](../adr/0048-author-role.md): an `author` adds and reads material as an `owner` or `admin` does.
- [ADR 0055](../adr/0055-pdf-text-in-the-browser.md): the console reads a PDF's text layer in a worker, within budgets, and the owner reviews its pages before saving them.
- [ADR 0046](../adr/0046-material-in-steps.md), accepted, not built yet: files uploaded together and listed, extracted in the background into snapshots, saved as sources; uncited sources deletable.
- [ADR 0047](../adr/0047-structured-items.md), accepted, not built yet: structured items, such as a question bank's, validated and converted by Braivo into keyed tasks; pictures on tasks.

## Gaps

| Gap                                                                                                               | Impact                                                                                                                                                                   | Next step                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nothing deletes a source, a file, or a citation                                                                   | Mistakes and test material stay in the library; an organization with any of them cannot be deleted                                                                       | Deleting a file or source nothing names or cites (ADR 0046); then decide what removing a cited source does to derived content and learning history |
| A source cannot be edited, title included                                                                         | A typo in a title means adding the source again, and what cites the first keeps showing the typo to learners                                                             | Decide whether a title can be renamed without making another source                                                                                |
| One file per upload, and no listing of files or their names                                                       | Twenty worksheets are twenty trips through the form; a file uploaded but never added as a source (a refusal, or leaving mid-add) is stored where nobody sees it          | Several files per pick, each its own upload, and a file library (ADR 0046)                                                                         |
| A source names at most one original                                                                               | The photos of one worksheet cannot be one source with its photos as provenance                                                                                           | Several files as one extraction, each source page knowing its file (ADR 0046)                                                                      |
| A file is read, or a source added, only in one request                                                            | A book is read a chapter at a time, by hand; leaving the page loses the work (see [generation](generation.md))                                                           | Extraction as a background job, sampled first, a batch of pages at a time (ADR 0046)                                                               |
| Pictures are not part of a source, and a task cannot show one                                                     | Questions that depend on a picture cannot be practised, such as most of a driving-theory bank                                                                            | Pictures on tasks (ADR 0047); meanwhile importers leave such questions out and list them                                                           |
| Braivo knows nothing of a question bank's structure: its numbered statements, their groups, answers, and pictures | An importer writes every statement as a task, twice (prompt and quote); a re-import revives what the owner corrected or retired unless the importer keeps its own record | Statement groups validated and converted by Braivo, and keyed tasks (ADR 0047)                                                                     |
| A hosted assistant (Claude, ChatGPT) cannot bring a file, list files, or have one read                            | Material is added in the console or by the CLI first; writing a book inline costs an assistant its whole length in output                                                | The file channel on remote MCP (ADR 0046)                                                                                                          |
| Files over 50 MB have no upload path                                                                              | A video cannot be kept as an original                                                                                                                                    | A presigned upload straight to the store, recorded afterwards (ADR 0028)                                                                           |
| Learners cannot open an original                                                                                  | A learner told "p. 12" needs their own copy of the book                                                                                                                  | Product decision: whether an organization may share originals with its learners                                                                    |
| Braivo never fetches a link: a YouTube video's or an article's text must be extracted by the sender               | A teacher with only a link needs `yt-dlp` or an agent before adding it                                                                                                   | None: the sender extracts (ADR 0020); fetching server-side waits until teachers adding by link need it                                             |
| Reading a PDF in the console bounds its time and text, not its memory                                             | A hostile PDF can crash the owner's tab while it is read, losing what the form held                                                                                      | Extraction on the server under a memory limit (ADR 0046)                                                                                           |
| A PDF's review is lost on leaving                                                                                 | A long book's corrections are gone if the owner leaves the page before saving                                                                                            | Extractions kept as snapshots (ADR 0046)                                                                                                           |
| A PDF's text is read in drawing order, without layout analysis                                                    | Columns drawn line by line across the page interleave, and the owner corrects them in review or pastes the text                                                          | Layout analysis when schools' PDFs need it                                                                                                         |
| The console's reader does not detect every damaged page                                                           | A corrupt compressed stream reads as whatever it decodes to, so part of a page can pass as read; only the owner's review against the PDF shows it                        | Report it once pdf.js surfaces what it recovers from                                                                                               |
| A source's text is at most 10 MB per request                                                                      | A long book must be split into several sources by hand                                                                                                                   | Split by chapter in the CLI, or raise the limit once locating quotes is indexed                                                                    |
