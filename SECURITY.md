# Security Policy

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/braivo/braivo/security/advisories/new), or by email to hello@braivo.app. Do not open a public issue, pull request, or discussion for it.

Include what is affected, how to reproduce it, and what an attacker gains. You will hear back within a week. Once a fix is released, the advisory is published, crediting you unless you prefer otherwise.

## Supported versions

Braivo is pre-release: only the latest commit on `main` is supported, and fixes land there. Hardening an installation, such as putting the server behind a proxy, is covered in [the deployment guide](docs/guides/deployment.md).
